# Bayan brand assets

Rendered, ready-to-use images from the [design system](../../app/design-system/readme.md).
The source of truth is `app/design-system/` (logo SVGs, tokens, and `Bayan Banners Final.dc.html`);
the PNGs here are 1500×500 banners exported at 2× (3000×1000).

| File | Use |
|---|---|
| `banners/bayan-banner-editorial-light.png` / `-dark.png` | README hero (switches with the viewer's theme) |
| `banners/bayan-banner-lockup-light.png` / `-dark.png` | Logo-only banner |
| `banners/bayan-banner-product-light.png` | Product banner with the reader panel |
| `banners/bayan-banner-sunrise-dark.png` | Dark social banner |
| `social-preview.png` | GitHub social preview (1280×640). Upload it in repo Settings → Social preview |

Logos and icons live in `app/design-system/assets/logo/` and `app/design-system/assets/icons/`.
