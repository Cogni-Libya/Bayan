Turn 4 · Dyslexia-friendly typography
Turn 3 banners, set for dyslexic readers
Latin text is set in OpenDyslexic, whose weighted letter bottoms reduce flipping and swapping. There is no OpenDyslexic for Arabic, so Arabic stays in Readex Pro (an Arabic extension of Lexend, which was built for reading fluency), set larger with wider word spacing and taller lines. Letter-spacing is not used on Arabic because it breaks the joins. Light weights are removed and secondary text has higher contrast.
