Primary action control; use `primary` (ink) for the main action and `accent` (ochre) at most once per view.
```jsx
<Button variant="primary">ابدأ القراءة</Button>
<Button variant="secondary" size="sm">حفظ</Button>
```
Variants: primary · accent · secondary (1.5px ink outline) · ghost · danger. Sizes sm 36 / md 44 / lg 52 (44px minimum touch target). Icons via `iconStart`/`iconEnd` (logical — flips in RTL).
