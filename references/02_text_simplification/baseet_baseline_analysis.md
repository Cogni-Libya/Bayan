# Baseet Baseline: Independent Re-analysis of Its Predictions

Supports: choosing baselines for Final Report 3.3/3.5, and Bayan's data-pipeline design.
Analysis run 2026-09-17 on Baseet's published prediction files.

**Baseet** (University of Jeddah graduation project; GitHub `raya-y/Baseet`, no license file; local copy
`capstone_data/Baseet`) fine-tunes AraT5v2 and AraBART with `[L_1]/[L_2]/[L_3]` level tokens on 34,294
source sentences (BAREC-derived "Bayyin" + SAMER fragments) whose simplified targets were generated by
**Aya-8B**. Its README reports a "hybrid" AraT5v2 + lexical-substitution model as best (SARI 54.36 /
54.81 / 53.56).

---

## 1. Data used

Prediction CSVs from Baseet's Google Drive folder "predictions"
(`drive.google.com/drive/folders/1HynWxeKXdbXMi5amzZE5h3kfaXCXxbOH`, ~2.8 GB): one file per model with
`Original_Sentence`, `ref_level_{1,2,3}` (Aya-8B targets), `pred_level_{1,2,3}`, and for hybrids
`hybrid_level_{1,2,3}` plus the lexical module's substitutions. All files contain all 34,294 rows in the
same order.

## 2. Findings

### 2.1 The headline hybrid score was computed on the whole dataset
`evaluation/hybrid-models-simplification-evaulation.ipynb` loads the full CSV and scores all 34,294
rows — about 80% of which were the model's **training** sentences. The AraT5v2-only numbers in the README
come from a held-out test split. The two sets of numbers are therefore not comparable.

### 2.2 On the real test split, the hybrid does not beat AraT5v2
The split was reconstructed exactly from the notebook (`train_test_split`, seed 42, 80/10/10 →
27,435 / 3,429 / 3,430, matching the notebook's printed counts). SARI with Hugging Face `evaluate`,
single Aya-8B reference, 0–100:

| Level | Copy the input | AraT5v2 | Hybrid (AraT5v2 + lexical) |
|---|---|---|---|
| L1 (strong) | 39.18 | **51.53** | 51.26 |
| L2 | 43.52 | **53.28** | 50.73 |
| L3 (mild) | 45.61 | **53.68** | 50.07 |

The lexical post-processing lowers SARI at every level.

### 2.3 The lexical substitution module damages meaning
The hybrid's lexical step changed at least one word in **57.2%** of Level-1 outputs (mean 1.01
substitutions per sentence). In a random sample of 12 substituted sentences, 11 substitutions changed
the meaning, including two negation flips:

| Original → substituted | Meaning change |
|---|---|
| الفرنسية → الالمانية | French → German |
| البوذيين → العرب ; لسنا → نكون | Buddhists → Arabs; *we are not* → *we are* |
| لست → كنت ; مارقاً → ملكا | *I am not* → *I was*; renegade → king |
| حائرٌ → صحيح | confused → correct |
| تائه → راض | lost → satisfied |
| تعطلت → وجاءت ; عمدة → حكومة | broke down → and came; mayor → government |
| عدم الانحياز → عدم الرضا (first row of the dataset) | non-alignment → dissatisfaction |

A BERT masked-language-model substitution filtered only by lemma/POS/frequency picks words that *fit the
context*, not words that *mean the same thing*.

### 2.4 Other observations
- **Copy-the-input already scores SARI 39–46** against these references, so SARI gains must be read
  relative to that floor.
- **SARI depends on the implementation:** Baseet's README reports AraT5v2 at 43.84 / 46.13 / 45.96 on the
  same test split (EASSE-based scoring in its notebook); Hugging Face `evaluate` gives 51.53 / 53.28 / 53.68
  for the same outputs — about 8 points higher.
- **Level control is weak:** 11.4% of AraT5v2 test outputs are identical across all three levels, and the
  notebook's own demo shows L1, L2 and L3 producing the same sentence (with the first clause deleted).
- **References are LLM-written (Aya-8B)**, so all of these scores measure agreement with Aya-8B, not with
  human simplifiers.

## 3. Implications for Bayan

1. Use **plain fine-tuned AraT5v2** (not the hybrid) as the Baseet-style baseline, and compare on the
   **same held-out split**.
2. **Do not add unconstrained masked-LM word substitution.** Any lexical step needs a meaning check, and
   negations must be protected.
3. Always report the **copy-the-input** baseline and the **exact SARI implementation** used.
4. Test level control explicitly (how often outputs differ across levels, and whether readability drops).
5. Evaluate against **human-verified** references, not only LLM-written ones.
